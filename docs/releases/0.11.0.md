# Source Scraper v0.11.0 Beta 1 — performance and single release

The main product remains the **standalone JSON-first CLI**. Obsidian is optional. This version makes a dedicated profiling and optimization pass without introducing a graphical interface or changing the v1 JSON data contract.

## Improvements

- Per-connection SQLite statement reuse in both legacy and generic stores to reduce repeated SQL compilation on individual observations.
- New additive indexes for project/entity reviews, assessment history and changes, plus a partial index to avoid repeated full-table scanning when restoring old observation snapshots.
- `json-file` and `json-snapshot` collection use run-scoped input caching, rather than reopening and parsing the whole input for every page. Snapshot revision hashes are calculated once per run.
- Bounded JSON and NDJSON output streaming (up to 500 records per batch), to stdout or create-only files. No unbounded intermediate exported-entity array or second entire JSON string.
- Regression tests cover index query plans, statement reuse, consistent multi-page input, run-to-run reloads and existing review/Obsidian workflows.
- Offline benchmark compares v0.10.0 to v0.11.0 on the same Linux runner for 1,200 entities / 12,000 review rows and 6,000 observations paginated in chunks of 50.

See [performance profiling](https://github.com/ibbuilds/source-scraper/blob/v0.11.0-beta.1/docs/performance.md), [README](https://github.com/ibbuilds/source-scraper/blob/v0.11.0-beta.1/README.md) and [CLI](https://github.com/ibbuilds/source-scraper/blob/v0.11.0-beta.1/docs/cli.md).

## Release distribution policy

**Only v0.11.0-beta.1 is retained on the repository's GitHub Releases page.** The trusted, CI-gated publisher deletes all older GitHub Release entries before publishing this build and verifies that none remain. Historical **Git tags and commits stay intact** for source history, but their removed download assets no longer resolve.

Release assets: standalone `source-scraper.mjs` (Node >=22.16), local npm installable `source-scraper-0.11.0.tgz` (**not npm registry published**), and optional `obsidian-x-feed-scraper.zip` for existing plugin installations.

## Start without Obsidian

```sh
node source-scraper.mjs init --dir ./demo
node source-scraper.mjs run --config ./demo/project.json
node source-scraper.mjs export --config ./demo/project.json --out ./results.json
```

No internet is used by the synthetic starter. The default SQLite database stays beside the manifest, and exports remain opt-in and create-only.

## Remaining limitations

The account-personalized, algorithmically ranked X **For You** feed still has no verified provider-authorized adapter. There is no claim of access to a personal X session or real-vault acceptance. Public-source latency, license/relevance heuristics, real webhook receivers and OS sandboxing for trusted custom extensions remain outside the scope of this offline performance pass.
